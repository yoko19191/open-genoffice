Pi Runtime IPC 与 Session 进程拓扑

每个 Electron 应用进程拥有一个受管 sidecar；renderer 只消费 typed bridge，Pi AgentSession、模型、MCP 与 Subagent 都留在受信 Runtime。虚线表示认证或权限边界。

protocol 1 · exact match

Session ownership

  • • Pi AgentSession 是唯一 transcript 与 run 事实源
  • • 一个 sidecar 管理多条 Session；一条 Session 只绑定一个文档
  • • renderer reload 不改变 Session 或活跃 run

IPC security

  • • inherited stdin 传 endpoint、父 PID 与一次性 256-bit token
  • • UDS / Named Pipe 只接受精确版本 hello
  • • renderer 永远接触不到 socket、secret 与真实 artifact path

Failure semantics

  • • 同文档 mutation 严格串行，readonly 可并行但结果有序
  • • Stop 贯通 model、tool、MCP 与 Subagent
  • • Runtime crash 标记 interrupted，不自动重放不确定操作
